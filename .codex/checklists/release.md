# Release Checklist

Before deploying or merging a release-sized change:

- [ ] Tests pass locally or in CI.
- [ ] SAM template remains valid.
- [ ] Deployment docs are current.
- [ ] New environment variables are documented.
- [ ] DynamoDB item changes are documented.
- [ ] Rollback path is clear.
- [ ] Quota/cost impact is acceptable.
- [ ] Privacy/security notes are updated if needed.
