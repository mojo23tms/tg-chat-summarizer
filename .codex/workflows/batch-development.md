# Batch Development Workflow

Use this workflow for roadmap implementation.

1. Read `AGENTS.md`, `CODEX.md`, and the roadmap.
2. Identify the next incomplete batch.
3. Inspect the current implementation and tests.
4. State the smallest safe plan.
5. Implement only this batch.
6. Add or update tests.
7. Update documentation.
8. Run available verification.
9. Summarize changes and stop.

Do not jump ahead to later batches unless the current batch explicitly requires a small supporting change.
