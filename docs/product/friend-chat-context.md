# Friend Chat Product Context

This bot is built for a private Telegram group of friends.

It should not feel like Slack AI, Jira AI, or a productivity assistant. It should understand and preserve the culture of the chat.

## What Matters

- running jokes;
- memes;
- nicknames;
- dumb recurring arguments;
- legendary incidents;
- funny quotes;
- who usually says what;
- stories that keep getting referenced;
- monthly or yearly recaps;
- keeping connection alive when the chat moves fast.

## Tone Target

The bot can be casual and culturally aware, but it should not force jokes or become the main character. It should be useful first, funny when appropriate, and careful with unsafe or hateful content.

## What Not To Build

Avoid corporate concepts unless the user explicitly asks for them:

- action items;
- owners;
- project decisions;
- meeting summaries;
- productivity dashboards.

Friend-chat memory is more like lore than project management.
